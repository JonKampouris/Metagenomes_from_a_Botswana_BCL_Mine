# Metagenomes_from_a_Botswana_BCL_Mine
[[!https://img.shields.io/badge/preprint-prepint[preprint]](https://doi.org/10.64898/2026.05.29.728080)

The repository contains the scripts for analysis of soil metagenomes from a polluted mine area in Botswana.

Title:
**Genome-resolved metagenomics reveals the potential for selection for antibiotic resistance due to metal pollution in soil microbial communities near a copper-nickel mine site in Botswana**
